PROMPT B — DESIGN MEDIASTUDIO

Design MediaStudio as a credible browser-based creative editor.

Avoid making it look like a generic dashboard.

The editor should prioritize the canvas.

LAYOUT:
- top toolbar
- left tools
- center canvas
- right properties/layers
- bottom zoom controls

Use compact tool controls.

The canvas should have:
- checkerboard transparency background
- zoom indicator
- rulers where practical
- selection handles

LAYERS PANEL:
Create a professional layer list with:
- thumbnails
- names
- visibility
- lock

PROPERTIES:
Show contextual controls based on the selected object.

Use local SVG icons.

Avoid:
- giant rounded cards
- unnecessary gradients
- excessive glassmorphism

Make the tool feel like actual software.
