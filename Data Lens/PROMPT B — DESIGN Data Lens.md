PROMPT B — DESIGN DATALENS

Design DataLens as a serious analytics and business-intelligence application.

It should feel comparable to professional data tools, not an AI dashboard.

Visual goals:
- dense but readable
- analytical
- structured
- precise

Avoid:
- giant dashboard cards
- excessive rounded containers
- random gradients
- decorative illustrations

LAYOUT:
Create:
- dataset sidebar
- main analysis workspace
- properties/configuration panel

TABLE:
Use excellent spreadsheet-style typography and alignment.

CHARTS:
Give charts:
- proper axes
- labels
- legends
- tooltips
- clean spacing

Dashboard widgets should prioritize data instead of decoration.

Use strong visual hierarchy for:
- primary KPI
- trends
- comparisons
- outliers

Create light and dark themes.

Include polished loading and empty states.
