PROMPT B — DESIGN CANVASFLOW

Redesign CanvasFlow so it feels like a professionally designed modern creative application and NOT like an AI-generated UI.

VISUAL DIRECTION:
Study the design language of professional productivity applications, vector tools, whiteboarding tools, and developer products.

The interface should feel:
- precise
- lightweight
- technical
- creative
- calm
- professional

DO NOT use:
- giant gradients
- excessive glassmorphism
- random floating blobs
- generic purple/blue AI gradients
- excessive rounded cards
- decorative elements without purpose
- huge hero sections
- marketing-style landing page patterns inside the app

APP LAYOUT:
Create:
- compact top toolbar
- left tool rail
- contextual right properties panel
- optional bottom status bar
- floating minimap
- canvas occupying the majority of the viewport

The UI should resemble a serious desktop creative application.

TOOLS:
Use consistent monochrome/local SVG icons instead of emojis.

Each tool needs:
- clear active state
- tooltip
- keyboard shortcut
- disabled state when appropriate

PROPERTIES PANEL:
When an object is selected, show relevant controls dynamically.

For example:
Rectangle:
- fill
- stroke
- opacity
- corner radius

Text:
- font
- size
- weight
- alignment
- color

Line:
- thickness
- arrowhead
- style

DESIGN DETAILS:
Use:
- subtle borders
- controlled shadows
- compact spacing
- excellent alignment
- restrained corner radii
- strong contrast
- consistent typography

Create polished dark and light themes.

Add subtle interaction feedback:
- selection animations
- hover states
- active tool transitions
- contextual panels appearing smoothly
- zoom indicators

Mobile/tablet mode should replace the desktop panels with a touch-friendly interface.

The final result should look like a product that could realistically compete with established whiteboarding software.
